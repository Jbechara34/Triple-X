Miner Configuration

How to connect a miner:
  • Point your miner at the pool URL above (e.g. XMRig -o <URL>).
  • Use any custom name you like as the worker username — it identifies this rig on the Pool/Blocks tabs.
  • The password is not checked — leave it blank or use x.
  • Example: ./xmrig -o <URL> -u my-rig-name -p x
